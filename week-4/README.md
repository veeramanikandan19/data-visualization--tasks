# Week-4 

## 📊 Project Overview

This project performs **data visualization and basic stock analysis of Shopify stock data using Python**.

The project uses historical Shopify stock-market data and analyzes the stock's closing-price movement, moving averages, and daily returns.

The analysis is implemented in both a **Python `.py` file** and a **Jupyter Notebook `.ipynb` file**.

## 🎯 Objectives

The main objectives of this project are:

* Load and understand historical Shopify stock data.
* Visualize Shopify's closing price over time.
* Calculate the 20-day Simple Moving Average (SMA).
* Calculate the 50-day Simple Moving Average (SMA).
* Compare closing prices with moving averages.
* Calculate daily percentage returns.
* Analyze the distribution of daily returns.
* Generate histogram and KDE plots for daily returns.

## 📁 Dataset

The project uses:

```text
shopify_stock.csv
```

The dataset contains **2,469 rows and 7 columns**.

### Dataset Columns

| Column      | Description                        |
| ----------- | ---------------------------------- |
| `date`      | Date of stock trading              |
| `open`      | Opening stock price                |
| `high`      | Highest stock price during the day |
| `low`       | Lowest stock price during the day  |
| `close`     | Closing stock price                |
| `adj_close` | Adjusted closing price             |
| `volume`    | Number of shares traded            |

The dataset covers historical Shopify stock data from **May 21, 2015 to March 14, 2025**.

## 🔍 Analysis Performed

### 1. Data Loading and Understanding

The Shopify stock CSV file is loaded using Pandas.

```python
df = pd.read_csv("shopify_stock.csv")
```

The first few records are displayed to understand the structure and contents of the dataset.

### 2. Closing Price Visualization

A line plot is created to visualize Shopify's closing stock price over time.

This provides a basic view of how the closing price changes throughout the dataset.

### 3. 20-Day and 50-Day Moving Averages

The project calculates two Simple Moving Averages:

* **20-Day SMA**
* **50-Day SMA**

They are calculated using:

```python
df['SMA_20'] = df['close'].rolling(window=20).mean()
df['SMA_50'] = df['close'].rolling(window=50).mean()
```

The closing price and both moving averages are plotted together for comparison.

### 4. Daily Returns

Daily stock returns are calculated using the percentage change in closing prices:

```python
df['Daily_Return'] = df['close'].pct_change() * 100
```

The first missing value generated by the calculation is removed before analysis.

### 5. Histogram of Daily Returns

A histogram is generated to show the frequency distribution of Shopify's daily returns.

This helps visualize how frequently different daily return values occur.

### 6. KDE Plot

A **Kernel Density Estimate (KDE)** plot is generated using Seaborn.

The KDE plot provides a smooth representation of the distribution of daily returns.
